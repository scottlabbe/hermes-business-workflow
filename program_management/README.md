# Program Management Workflows

This workspace is for public-safe Hermes workflows that support program management, monitoring, reporting, and operations.

Current contents:
- `cost-reports/test_data/`: demo salary-report workbooks for a future cost-report desk review workflow

Before using the cost-report workflow in a public demo, add:
- a workflow-specific `AGENTS.md`
- a README explaining the demo task and input assumptions
- an output contract
- a `runs/` folder with generated artifacts and `run_summary.md`
