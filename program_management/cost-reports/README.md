# Cost Report Desk Review

This folder contains demo inputs for a future program-management cost-report desk review workflow.

Current contents:
- `test_data/`: sample salary-report workbooks
- `runs/`: generated run outputs
- `workpapers/`: disposable analysis workpapers

Before this workflow is used in a public demo, add a workflow-specific `AGENTS.md` that defines:
- expected inputs
- required calculations
- output artifacts
- review checks
- public-safe data assumptions

Do not treat the current folder as an operational workflow until those instructions exist.
